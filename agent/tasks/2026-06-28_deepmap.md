## Task
Create `deepmap/` folder integrating robot rotation control with depth-anything to produce a 360° depth map.

## Input
- Robot UART on `/dev/ttyUSB0` (ESP32 Unified Controller, same protocol as motivation)
- USB camera (index 0 by default)
- depth-anything/src pipeline (merge_360.py, depth_to_3d_timed.py)

## Expected output
- `deepmap/shots/shot_NNN.jpg` — images captured at each angle
- `deepmap/shots/angles.csv` — manifest: `filename, angle_deg`
- `deepmap/output/map_360.ply` — merged 360° point cloud

## Plan
1. Create `deepmap/rotate_scan.py` — Feature 1
   - Open pyserial on /dev/ttyUSB0 at 115200
   - Wait for READY, send R (reset odometry)
   - Loop N steps (default 30° → 12 shots):
     - Capture camera frame → save shot_NNN.jpg
     - Record cumulative angle in manifest
     - Send `T <step_deg> <omega>\n` to ESP32
     - Wait for `K\n` ack before next step
   - Write shots/angles.csv

2. Create `deepmap/build_map.py` — Feature 2
   - sys.path add depth-anything/src
   - Reuse: list_images, load_angles, transform_to_world, write_ply, icp_merge from merge_360
   - Reuse: CFGS, pick_device, step_prep, step_infer, step_project from depth_to_3d_timed
   - Load model, run depth pipeline per frame, merge into 360° PLY
