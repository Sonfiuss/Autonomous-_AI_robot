## Decisions made
- All workers live in stereo_walk_map.py (only the bus is a separate module):
  FusionMapper needs the walk geometry, and a separate workers module would
  have needed circular imports or injection for no gain. Future voice/detect
  workers depend on pipeline_bus only.
- join_all re-offers the pill while joining (bugfix: one 5s put attempt was
  lost when DepthWorker's queue was still full of real pairs → 180s hang).
- Injection flags placed where they exercise the right tier: crash in
  DepthWorker (SystemExit → stop_event path), bad frame in StereoWorker
  (err-msg → skip path).

## Test results (offline, Windows dev box, torch CPU, no open3d → concat)
- Regression: per-stop output identical pre/post split
  (golden=41, inl=8, rms=0.0888, pts=72696).
- Sequential 28931 pts / 26.6s wall; pipeline 28867 pts / 21.9s wall
  (counts within voxel tolerance; floor-fit RANSAC jitters ±0.2%).
- Timing law holds: wall ≈ N×max(stage) + compute tail (3×6.9s + ~1s).
  Sum-of-stages 25.8s → overlap ×1.18 on CPU (depth-bound here; the Jetson
  has GPU depth + real ~3s drives, so overlap should approach the 2–3× goal).
- Crash@1: stop_event, no new move, clean join, partial 1-stop map saved.
- Badframe@1: stop skipped, walk continued, 2 stops fused, skip list printed.
- Windows console needed PYTHONIOENCODING=utf-8 (explore_map prints '→');
  irrelevant on the Jetson.
