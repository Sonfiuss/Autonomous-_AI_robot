# 2026-09-07 — RM module (project/)

## Implemented
- New standalone C++14 library `project/` (RM = kinematics logic layer for the 3-wheel omni base),
  written to embed on ESP32: float only, no heap/exceptions/RTTI/iostream, caller passes dt.
- `config/constants.h` — chassis from project_overview (a 0.055 m, L 0.21 m, wheels 60/180/300°,
  200 full steps × 64 microstep), MAX_PULSE_HZ 20 kHz placeholder, accel/decel 2 rad/s², odometry
  counts = commanded microsteps (no encoder yet; ENCODER_PPR/QUADRATURE kept for later).
- `OmniKinematics` (general IK matrix, exact 3×3 inverse FK, world↔body), `VelocityProfile`
  (slew limiter with common scaling to keep motion direction) + `TrapezoidalProfile`, `Odometry`
  (mid-point heading integration, O(1) wrap), `DriverStepDir` (ω↔Hz/DIR, angle/dist↔steps) +
  `StepAccumulator` (steps emitted per tick → feeds odometry without encoder).
- `CMakeLists.txt` (PC lib+tests, auto-registers as ESP-IDF component), `library.json` (PlatformIO),
  `README.md` embed guide + control-loop sketch, `tests/test_rm.cpp` (all pass on MinGW g++ 6.3).
