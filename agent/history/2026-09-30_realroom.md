## Decisions
- The page never drives by itself: Run starts demo_drive, Stop is the tested Ctrl-C path.
- "lập bản đồ" replaces the whole map (runs are not merged yet); never after a dry run, a run that ended where nobody
  knows, or a run the user stopped.
- A route is driven only from the pose it was planned from (checked while holding the robot lock).
- Additions beyond the plan (logged): flock, `--run-dir`, SIGINT reset, `REALROOM_MAPS_DIR`, `stop_requested`.
