# Activity log — 2026-06-28

## deepmap module — new (session summary)

**What was implemented:**
- `deepmap/rotate_scan.py` — Feature 1: rotates robot 360° in configurable steps via ESP32 UART
  (`T <deg> <omega>\n` command), captures camera frame at each stop, waits for `K` ack,
  writes `shots/angles.csv` manifest. `--dry-run` flag for testing without robot.
- `deepmap/build_map.py` — Feature 2: imports depth-anything/src pipeline (DRY), reads
  shots + angles.csv, runs Depth Anything V2 per frame, merges all point clouds into
  `output/map_360.ply`. Supports `--icp`, `--voxel`, `--show` via open3d.
- `agent/plan/deepmap_plan.md` — created plan file for this new module.

**Decisions made:**
- Capture image FIRST at current angle, then command rotation (natural 0° start).
- Used cumulative commanded angle for CSV (not odometry readback) — simpler & repeatable.
- `build_map.py` imports `merge_360.py` helpers directly rather than copying code.

**Interface used:** `T <angle_deg> <omega_rads>\n` + `K\n` ack (same as motivation MotionClient).

**Pending:** web viewer integration, FOV auto-calibration.
